# 📝 Todo App

A simple task management application built with React that allows users to add and delete tasks dynamically.

---

## 🚀 Features

- Add new tasks
- Delete tasks
- Real-time UI updates using React state
- Responsive design

---

## 🛠 Tech Stack

- React
- JavaScript (ES6+)
- CSS
- Vite
- Git & GitHub

---

## 📦 Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/todo-app.git
cd todo-app
npm install
npm run dev
